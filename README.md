# DeFi ModelGuard

DeFi ModelGuard is a beginner-friendly prototype for checking basic decentralized finance (DeFi) lending calculations.

## Features

- Calculate collateral ratios.
- Estimate maximum debt based on a target collateral ratio.
- Compare a position against a minimum collateral requirement.
- Accept Solidity source code for basic text-pattern checks.

## Technology

- Python
- Streamlit
- Pandas
